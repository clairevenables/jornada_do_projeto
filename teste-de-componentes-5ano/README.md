# Cidade em Alerta · 5º ano

Teste de Componentes do projeto "Cidade em Alerta".
Protagonistas Lab, Metodologia InterCriativa. Versão beta para teste em sala.

- 3 semanas
- 6 aulas de 50 minutos

## Aulas

1. Entender: Escolha do Desafio
2. Investigar: Cruzamento de Evidências
3. Idear: Escolha da Solução
4. Prototipar e Testar: Prototipagem de Baixa Fidelidade
5. Apresentar: Pitch Fundamentado em Evidências
6. Refletir e Avaliar: Reflexão e Continuidade

## Como abrir

Abra `index.html` no navegador. É uma página única, sem build.

Para publicar: GitHub, Settings, Pages, Source: `main`, pasta `/ (root)`.

## Origem

Exportada do artifact "Fifth grade project week one". As 6 aulas estão dentro do `index.html`.
